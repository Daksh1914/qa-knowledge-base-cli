# Q&A Management System

## Description
This project is a simple **Q&A Management System** that allows users to:
- Add, view, update, and delete **questions**.
- Add, view, update, and delete **answers** linked to specific questions.
- Store **questions and answers persistently** in text files to retain data across sessions.

## Features
- **Short IDs for Questions & Answers** (e.g., `Q1`, `Q2`, `A1`, `A2`).
- **CRUD operations** for both questions and answers.
- **Persistent storage** (data is saved and loaded from files).
- **User-friendly console interface** for easy interaction.
